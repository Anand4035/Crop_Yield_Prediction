# Crop_Yield_Prediction
AI-powered Crop Yield Prediction system that helps farmers estimate crop production using machine learning. Built using Python, Flask, Scikit-learn, and Random Forest with a modern glassmorphism web interface. Predicts crop yield based on rainfall, temperature, pesticides usage, country, and crop type for smart agriculture solutions.



# 🌾 Crop Yield Prediction Using Machine Learning

An AI-powered Crop Yield Prediction System built using Machine Learning, Flask, and Random Forest Algorithm.  
This project predicts crop yield based on environmental and agricultural factors such as rainfall, pesticides usage, temperature, country, and crop type.

---

# 🚀 Project Overview

Agriculture plays a vital role in the economy and food production.  
This project helps farmers and agricultural industries predict crop yield using historical agricultural datasets and machine learning techniques.

The system provides:
- Crop yield prediction
- Smart farming analytics
- Farmer-friendly web interface
- AI-powered prediction system
